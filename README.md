# Win11Lite: Оптимизация Windows 10/11 x64 для слабых ПК и ноутбуков

Специализированный модульный PowerShell-скрипт оптимизации после чистой установки Windows 10 или Windows 11 (поддерживаются редакции **Home, Pro, Enterprise, LTSC 2019/2021, LTSB 2015/2016**).

Целевой профиль оборудования:
- Обычный механический жесткий диск (**HDD 5400 / 7200 RPM**);
- **4 ГБ оперативной памяти** (RAM);
- Интегрированное видеоядро (**Intel HD Graphics / AMD Radeon APU**).

---

## ⚡ Быстрый запуск одной командой

Откройте **PowerShell от имени Администратора** (`Win + X` -> *Терминал (Администратор)* или *PowerShell (Администратор)*) и вставьте:

### 1. Интерактивный режим с выбором пунктов (Рекомендуется):
```powershell
irm https://raw.githubusercontent.com/ntvampire/Win11Lite/main/start.ps1 | iex
```
*(Скрипт автоматически скачивает свежий архив с GitHub, распаковывает его во временную папку и открывает интерактивное меню)*

**Доступные пункты меню:**
- `[1]` **Полная комплексная оптимизация** (применяются все модули сразу);
- `[2]` **Оптимизация дисковой подсистемы** (HDD, NTFS, Pagefile, WSearch, SysMain);
- `[3]` **Оптимизация оперативной памяти и служб** (4GB RAM, сжатие памяти, телеметрия);
- `[4]` **Оптимизация графики и интерфейса** (iGPU, без прозрачности, с сохранением ClearType);
- `[5]` **Очистить мусорные приложения** (Bloatware, OneDrive, Outlook, сохранив Store и базу);
- `[6]` **Создать точку восстановления системы вручную**;
- `[0]` **Выход**.

### 2. Полностью автоматический режим (без вопросов) с перезагрузкой:
```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/ntvampire/Win11Lite/main/Optimize-Windows.ps1))) -Unattended -Restart
```

### 3. Запуск через локальный файл (если репозиторий уже скачан):
Нажмите правой кнопкой мыши на `Run-As-Admin.cmd` и выберите **"Запуск от имени администратора"** (или запустите `.\Optimize-Windows.ps1` в PowerShell).

## 🛡️ Гарантия сохранности системных компонентов
В отличие от агрессивных деблоатеров, скрипт **НЕ ломает систему и строго сохраняет**:
- **Защитник Windows (Windows Defender)**, SmartScreen и Центр безопасности;
- **Магазин приложений (Microsoft Store)** и сопутствующие службы установки UWP-пакетов;
- **Базовые системные программы**:
  - Калькулятор (`Calculator`)
  - Блокнот (`Notepad`)
  - Фотографии (`Photos`)
  - Камера (`Camera`)
  - Новый Медиаплеер / Музыка (`Media Player / ZuneMusic`)
  - Ножницы (`Snipping Tool / ScreenSketch`)
  - Классический Paint
- **Службу печати (Spooler)**, сеть, интернет и системные кодеки (HEIF, VP9, WebMedia, AV1).

## 🚀 Что оптимизирует скрипт?

### 1. Устранение 100% нагрузки на HDD (Диск)
- **Отключение времени последнего доступа NTFS (`DisableLastAccess`)**: устраняет лишние микрозаписи 4K при каждом обращении к файлам.
- **Статический файл подкачки (`pagefile.sys`)**: фиксирует размер виртуальной памяти (4096 – 6144 МБ), предотвращая фрагментацию диска и замирания ОС при динамическом расширении файла подкачки.
- **Delivery Optimization (WUDO)**: отключает фоновую P2P-раздачу обновлений в интернет, вызывающую внезапные 100% всплески нагрузки на HDD.
- **Отложенный запуск Windows Search и SysMain**: предотвращает "забивание" жесткого диска при старте рабочего стола. Сетевой поиск Bing в меню «Пуск» отключен.
- **Отключение тяжелых фоновых задач**: отключает задачи `Microsoft Compatibility Appraiser` (CompatTelRunner.exe), CEIP Consolidator и фоновые сканеры диска.

### 2. Оптимизация под 4 ГБ ОЗУ (Память и службы)
- **Сжатие памяти (Memory Compression)**: принудительно включает сжатие неактивных страниц в ОЗУ через `Enable-MMAgent -MemoryCompression` (чтение из сжатой RAM в сотни раз быстрее swap-файла на медленном HDD).
- **Отключение телеметрии**: отключает и останавливает службы `DiagTrack` и `dmwappushservice`.
- **Блокировка Consumer Experience**: запрещает фоновую установку спонсорских приложений и рекламных советов Windows.
- **Оптимизация второстепенных служб**: отключение неиспользуемых служб карт (`MapsBroker`), торгового демо-режима (`RetailDemo`), удаленного реестра; службы геолокации и Xbox переведены в ручной запуск.

### 3. Оптимизация графики для встроенного видео (iGPU)
- **Отключение прозрачности (Acrylic, Mica)**: разгружает видеочип и высвобождает пропускную способность общей памяти.
- **Отключение лишних анимаций**: устраняет микрофризы при сворачивании и разворачивании окон.
- **Сохранение читаемости**: **ClearType (сглаживание шрифтов) строго включено**, эскизы файлов в Проводнике сохранены.
- **Отключение фоновой записи экрана (Game DVR)**: освобождает видеобуферы.
- **Отключение виджетов ("Новости и интересы" / Widgets)**: освобождает до 250 МБ ОЗУ, убирая фоновый процесс Edge WebView2. Настройка адаптирована под версию ОС: на Windows 10 используется системная политика `EnableFeeds = 0`, на Windows 11 отключаются компоненты `Dsh`, `TaskbarDa` и `TaskbarMn`.

### 4. Очистка нежелательных приложений (Bloatware), OneDrive и Outlook
- **Полное удаление Microsoft Outlook (Новый, старый, UWP, Beta/Preview)**:
  - Принудительное завершение процессов `olk.exe`, `Outlook.exe`, `HxOutlook.exe`;
  - Удаление пакетов `Microsoft.OutlookForWindows` и системных образов подготовки (`ProvisionedPackage`) для всех пользователей;
  - Тихая деинсталляция автономных установщиков Outlook через системный реестр;
  - Очистка каталогов кэша и профиля (`%LocalAppData%\Microsoft\Olk`, остатки в `Packages`);
  - Удаление ярлыков Outlook из меню «Пуск» и с Рабочего стола;
  - Блокировка автоустановки и принудительного переключения через реестр и политики (`UseNewOutlook = 0`, `HideNewOutlookToggle = 1`, `PreventNewOutlook = 1`).
- **Полное удаление Microsoft OneDrive**:
  - Завершение процессов `OneDrive.exe` и запуск штатного деинсталлятора;
  - Удаление пользовательских переменных среды (`OneDrive`, `OneDriveConsumer`, `OneDriveCommercial`);
  - Полное удаление папки `OneDrive` из профиля пользователя и остаточных файлов в `AppData` / `ProgramData`;
  - Блокировка повторной установки через групповую политику (`DisableFileSyncNGSC = 1`);
  - Удаление значка OneDrive из панели навигации Проводника.
- **Удаление предустановленного мусора и сервисов**:
  - Microsoft OneNote;
  - Paint 3D и Print 3D (классический Paint сохранен);
  - Заметки (Sticky Notes);
  - Xbox, Xbox Live, игровые оверлеи Game Bar;
  - Люди (Microsoft People);
  - Почта и Календарь (windowscommunicationsapps);
  - Часы и будильники (WindowsAlarms);
  - Запись голоса (WindowsSoundRecorder);
  - Карты (WindowsMaps);
  - Кино и ТВ (ZuneVideo — плеер музыки и видео сохранен);
  - Погода (BingWeather);
  - Средство 3D-просмотра (3D Viewer);
  - Яндекс Музыка и региональные промо-пакеты;
  - Спонсорские игры и реклама (TikTok, Spotify, Disney+, Netflix, Candy Crush, Solitaire).

## ⚙️ Дополнительные параметры запуска (CLI)

Если вы запускаете скрипт из скачанной папки или передаете аргументы в PowerShell:
- **Автоматический режим без диалогов**:
  ```powershell
  .\Optimize-Windows.ps1 -Unattended -Restart
  ```
- **Пропуск создания точки восстановления**:
  ```powershell
  .\Optimize-Windows.ps1 -SkipRestorePoint
  ```
- **Выборочный пропуск модулей**:
  ```powershell
  .\Optimize-Windows.ps1 -SkipStorage -SkipServices -SkipVisuals -SkipBloatware
  ```
